# Ritmo Visual Refresh

Create a beautiful mobile-first visual prototype for a Brazilian personal finance app called **Ritmo**.

IMPORTANT:

Use the attached image as the main brand and visual identity reference.

The attached image defines the current Ritmo brand direction, including:

- logo

- colors

- typography style

- light and dark brand expressions

- overall tone and visual language

This task is ONLY about the visual experience of the app.

Do NOT focus on backend, logic, authentication, notifications engine, or integrations.

This is a **visual redesign project** for the product surface.

---

## PRODUCT CONTEXT

Ritmo is a personal financial organization app.

Its concept is:

**“Organização financeira que aprende com você.”**

The product helps users understand their financial life clearly and make better decisions over time.

The app should feel:

- clear

- modern

- calm

- intelligent

- premium

- approachable

- trustworthy

- mobile-first

It should NOT feel like:

- a traditional bank app

- a generic expense tracker

- accounting software

- a dashboard overloaded with charts

- a childish finance app

- a crypto or trading app

---

## DESIGN GOAL

Design what the user sees when opening the app on a phone.

The visual priority is:

1. clarity

2. hierarchy

3. beauty

4. ease of understanding

5. trust

The product already has strong intelligence in the background, but the user interface today is weak.

Your job is to create a visually strong, polished, elegant mobile app experience.

---

## PLATFORM

Design for **mobile first**.

Primary viewport should feel like a modern smartphone app interface.

Prioritize iPhone-sized screens around:

- 390 x 844

or similar proportions.

Do not prioritize desktop.

If desktop appears, it should only be secondary.

---

## BRAND REFERENCE

Use the attached brand board as the main inspiration.

### Primary identity

**Light mode = “Humana & Inteligente”**

This is the main/default app theme.

### Secondary identity

**Dark mode = “Premium & Tech”**

This is the optional dark theme.

The app must support both:

- light mode

- dark mode

The user must be able to switch between them.

Include a visible and well-designed **theme toggle** or theme selector inside the UI.

This can appear:

- in the header of the home screen

- or inside the “More / Settings” area

- or both

The switch between light and dark should feel elegant and natural.

## TYPOGRAPHY

Use the Ritmo visual style from the reference image.

The app should feel aligned with the approved brand system.

Typography should feel:

- strong headings

- elegant

- readable

- slightly soft

- premium but accessible

Use a visual direction similar to:

- Manrope for headings

- Inter for interface/content

Do not use decorative or playful fonts.

## APP STRUCTURE

Create a visual prototype with the following main mobile screens:

### 1. Home

This is the most important screen.

It should show:

- greeting

- overall monthly state

- a strong hero card with “Safe-to-Spend” style information

- a simple summary such as “Seu ritmo está tranquilo”

- upcoming commitments

- one insight/recommendation

- a clear CTA to open the assistant

- elegant bottom navigation

Example tone:

- “Boa noite, Douglas”

- “Seu ritmo está tranquilo”

- “R$ 1.842 disponíveis até o próximo salário”

Do not overcrowd this screen.

---

### 2. Planning / Monthly overview

A screen focused on monthly planning.

Show:

- current available amount

- expected income

- expected expenses

- recurring commitments

- planned events / reserved money

- a simple monthly timeline or structured sectioned view

It should not look like a spreadsheet.

It should feel visual, calm and understandable.

---

### 3. Assistant

Create a conversational financial assistant screen.

It should feel like a premium, trustworthy in-app assistant, not a generic chatbot.

Example quick actions:

- “Posso gastar hoje?”

- “Explique meu mês”

- “Como está meu ritmo?”

- “Me ajude a economizar”

- “Quanto sobra até o próximo salário?”

Design the assistant screen to feel useful and clean.

---

### 4. Transactions / Commitments

Create a screen with:

- financial movements

- recurring transactions

- subscriptions

- bills

- salary entries

- grouped items with clear labels

Focus on clarity and pattern recognition.

Examples:

- Aluguel

- Cartão de crédito

- Internet

- Academia

- Salário

---

### 5. Recommendations / Insights

Create a screen that feels helpful and actionable.

Examples:

- “Você está gastando 12% acima do seu ritmo habitual.”

- “Essa cobrança parece uma nova assinatura.”

- “Seu evento planejado ainda cabe no mês.”

- “Seu Safe-to-Spend caiu após novas despesas.”

This should feel intelligent but not alarmist.

---

### 6. More / Profile / Settings

Create a final utility screen with:

- theme switch (light/dark)

- account/settings placeholder

- notification preferences placeholder

- connected institutions placeholder

- help/privacy placeholder

No real auth or account flow is needed.

This is only visual.

---

## NAVIGATION

Use a simple bottom navigation with 4 or 5 items max.

Recommended tabs:

- Início

- Planejamento

- Assistente

- Insights

- Mais

Keep it clean and premium.

---

## VISUAL STYLE

The app should look like a premium consumer fintech with AI, but warmer and calmer than a bank.

Use:

- large rounded cards

- clean spacing

- strong visual hierarchy

- big key numbers

- soft shadows or subtle depth

- elegant icons

- very limited chart usage

- refined transitions if applicable

Do not overload screens with too many widgets.

---

## UX PRINCIPLES

The user should feel:

- “I understand my money”

- “I know what matters now”

- “This app is helping me”

- “This is clean and easy”

- “This looks premium”

Design for emotional clarity, not dashboard complexity.

---

## COPY STYLE

All UI copy should be in **Brazilian Portuguese**.

Use a tone that is:

- clear

- modern

- calm

- helpful

- intelligent

Do not use robotic or overly corporate language.

Use the approved brand message:

**“Organização financeira que aprende com você.”**

This message can appear in appropriate places, but do not overuse it.

---

Generate a polished visual prototype of the Ritmo app with:
